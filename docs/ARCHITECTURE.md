# Crypto Trading Analysis Dashboard

SMC and Elliott Wave are independent analysis engines. They share OHLCV market data but do not modify each other's results.

## Modules
- SMC Analysis: HH/HL/LH/LL, BOS, CHOCH, liquidity, sweeps, FVG, order blocks and premium/discount.
- Elliott Wave Analysis: impulse/corrective structures, primary and alternative counts, Fibonacci relationships, channels and invalidation.
- Combined Analysis: optional confluence view consuming both independent results.

## UI
1. SMC Analysis
2. Elliott Wave
3. Combined Analysis

Each analysis engine has independent chart overlays and enable/disable controls.
